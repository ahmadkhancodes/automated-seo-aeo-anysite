# Security policy

The scripts run locally, read and write files in your workspace, and make no network requests. The skill tells Claude to treat fetched web text as data, never as instructions.

## Reporting a problem
If you find a way to make the scripts read or write outside the workspace, run code from a post or config file, or a prompt-injection path the playbooks do not defend against, please report it privately through GitHub: **Security → Report a vulnerability** on this repository (https://github.com/ahmadkhancodes/automated-seo-aeo-anysite/security/advisories/new).

Please do not open a public issue for security problems. You will get a reply within 7 days.

## Supported versions
Only the latest release receives fixes.
